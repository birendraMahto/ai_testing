# AI Testing Workspace

This repository contains multiple AI-powered testing and automation frameworks built across different chapters and projects.

## Projects Included

- **[TestingBuddy.AI](./Chapter_4_AI_Agents/TestingBuddy/README.md) (Chapter 4):** An intelligent test management companion that helps QA teams plan, design, and execute testing strategies by generating Test Plans, Defect Reports, Test Cases, and Release Notes using Local (Ollama) or Remote LLMs, with direct Jira API integration.
- **Jobtracker_AI:** An AI-powered Job Tracker system.
- **Job_ATS_Resume_Builder:** An AI-driven ATS resume builder.
- **Local_Test_Generator:** Scripts to generate tests locally using AI.
- **B.L.A.S.T Framework:** Advanced AI software testing methodology.
- **Project_02_Prompt_Templates:** A comprehensive collection of prompts for AI engineering and software testing.

## Getting Started

Each project is contained within its own subdirectory and has its own isolated dependencies and setup steps. Please navigate to the respective directory and review the project's specific `README.md` for detailed instructions on how to start the backend and frontend servers.
